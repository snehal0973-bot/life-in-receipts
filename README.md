# Your Life, In Receipts - Pune Edition

Life is a collection of thermal receipts. Every ₹30 ticket is a memory.

## What I Built
- 12 real Pune receipts (FC Road, Shaniwar Wada, Metro)
- Search, Filter, Sort, Add new receipt
- Total spent, stats dashboard
- Print animation, barcode, responsive design
- Keyboard support (Tab, Enter, Esc)
- LocalStorage saves your receipts

## Tech
Pure HTML/CSS/JS - No frameworks - Fast & Offline
